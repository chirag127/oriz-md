About this project

oriz-md — Markdown Studio

A free, 100% client-side editor for GitHub-Flavored Markdown: live editor + preview, GFM, export to HTML/PDF. This is the project info page — the live tool is a separate app.

Open the live app → Source on GitHub llms.txt

What it is

oriz-md is a split-screen Markdown studio. Write GFM on the left, read the rendered preview on the right — in real time, entirely in your browser. Export a standalone .html or .md file, or print to PDF.

Key features

  • Live GFM preview — headings, tables, task lists, autolinks, strikethrough.
  • Syntax highlighting — highlight.js, lazy-loaded only when code appears.
  • Auto table of contents — built from your headings, with anchor links.
  • Export — download .html / .md, or print → PDF.
  • Focus mode — dims everything but where you're writing.
  • Optional AI assist — expand, summarize, fix markdown, or generate a TOC.
  • Autosave — persists to localStorage between sessions.
  • Drag & drop — drop a .md file to open it.
  • PWA — installable, works offline after first load.

Tech

Client-only Astro static site with a React 19 island · Tailwind v4 · marked + DOMPurify + highlight.js · g4f AI via @chirag127/oz-ai (keyless, multi-provider) · PWA-installable · 100% in-browser — no upload, no signup.

Private by design. Everything runs in your browser. Nothing is uploaded, no account is required, and there is no tracking. The optional AI buttons send only your document text, only when pressed.
